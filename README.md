# E-Commerce Sales and Customer Analysis

## Project Overview

This project is an E-Commerce Sales and Customer Analysis project created using Microsoft Excel.

The objective of this project is to analyze sales, customers, products, discounts, delivery charges, and order information to identify meaningful business insights.

## Business Problem

E-commerce businesses generate a large amount of customer and sales data. Analyzing this data helps businesses understand customer behavior, product performance, sales trends, coupon usage, and city-wise performance.

This project uses Excel to transform raw data into meaningful insights that can support business decision-making.

## Dataset

The dataset contains e-commerce order information including:

- Customer details
- Order details
- Product information
- Pricing information
- Discounts
- Delivery charges
- Sales information
- Coupon usage
- City information

## Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- Charts
- Data Analysis

## Methodology

The project was completed using the following steps:

1. Collected and reviewed the raw e-commerce data.
2. Cleaned and organized the data in Excel.
3. Used Excel formulas and calculated fields for analysis.
4. Created PivotTables to summarize the data.
5. Created charts to visualize important findings.
6. Analyzed customers, products, cities, coupons, and sales patterns.
7. Identified important business insights from the analysis.

## Key Insights

- Identified the top-performing customers based on order amount.
- Identified the best-performing products based on sales.
- Analyzed city-wise order and sales performance.
- Identified the most frequently used coupon.
- Analyzed sales patterns across different months.
- Studied customer and order-related information.
